# 01 - Excel Avançado

## Objetivo
Estruturar, padronizar e auditar a planilha bruta de vagas de TI e requisitos utilizando funções de Excel avançado (PROCX, validação de dados, auditoria de integridade e eliminação de erros como `#N/D`, `#REF!`, `#VALOR!`).

## Artefatos Esperados
- Planilha tratada e auditada (`.xlsx`)
- Registro/Log de inconsistências encontradas e premissas de tratamento adotadas
