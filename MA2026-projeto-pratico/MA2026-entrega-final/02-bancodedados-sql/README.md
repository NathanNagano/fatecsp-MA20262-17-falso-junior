# 02 - Banco de Dados Relacional (SQL)

## Objetivo
Modelar e implementar o banco de dados relacional para persistência, auditoria e consultas analíticas (DDL e DML) sobre a base histórica de vagas.

## Artefatos Esperados
- Script SQL DDL com a criação de tabelas, tipos de dados, chaves primárias e relacionamentos (`Script.sql`).
- Consultas SQL DML analíticas contendo agregações, joins e filtros estratégicos.
